# town-shots

Beautiful static gallery for Town / Voxelize screenshots and videos. Deployed via GitHub Pages at [https://shaoruu.github.io/town-shots/](https://shaoruu.github.io/town-shots/)

## Gallery Features

- **Minimal UI**: No header clutter—just the media
- **Masonry grid**: Pinterest-style responsive layout
- **Hover overlays**: Quick details with capture time (Pacific), annotation, and tags
- **Full-screen modal**: Click any tile to open lightbox with pan/drag, zoom (scroll/pinch), and keyboard navigation (←/→/Esc)
- **Video support**: Videos play in the modal

## Data Model

The gallery reads from a simple static structure:

```
public/
  media/          # All images (.png, .jpg, .webp) and videos (.mp4, .webm)
    example-1.png
    example-2.mp4
    ...
  manifest.json   # Single JSON file listing all media items
```

### Manifest Schema

`public/manifest.json`:

```json
{
  "items": [
    {
      "id": "unique-id",
      "src": "media/example-1.png",
      "type": "image",
      "capturedAt": "2026-09-18T14:32:00.000Z",
      "annotation": "Butterfly meadow in bloom",
      "tags": ["meadow", "butterflies", "nature"],
      "width": 1920,
      "height": 1080,
      "sourcePath": "/path/to/original.png"
    }
  ]
}
```

**Fields:**
- `id` (required): Unique identifier for the item
- `src` (required): Relative path from `public/` to the media file
- `type` (required): `"image"` or `"video"`
- `capturedAt` (required): ISO 8601 timestamp (displayed in Pacific time)
- `annotation` (optional): Short description
- `tags` (optional): Array of tag strings
- `width`, `height` (optional): Dimensions in pixels
- `sourcePath` (optional): Original file path for reference

## Syncing Media

To add new screenshots/videos:

1. **Copy media files** into `public/media/`
2. **Regenerate `manifest.json`** with entries for each file
3. **Push to `main`** — GitHub Actions will rebuild and deploy

The manifest can be generated by any script that scans `public/media/` and extracts metadata (timestamps, dimensions, etc.).

## Development

```bash
npm install
npm run dev       # Start dev server at http://localhost:5173
npm run build     # Build for production
npm run preview   # Preview production build
```

## Deployment

GitHub Pages is configured via Actions (`.github/workflows/deploy.yml`). Every push to `main` triggers a build and deployment. The site base path is `/town-shots/`.

To enable GitHub Pages:
1. Go to repository Settings → Pages
2. Set Source to "GitHub Actions"
3. The workflow will deploy on the next push
